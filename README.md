# Kokkos Demo - Game of Life

This repo provides a demo of integrating Kokkos into legacy code by using [Conway's Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life).
The CPU only ('legacy') file is `GameOfLife_CPU.cpp` while the Kokkos enabled file is `GameOfLife_Kokkos.cpp`.

## Dependencies

This demo relies upon Kokkos.
To make this easy, Kokkos 5.0.0 is downloaded by CMake.
To enable the CUDA (or other device) backend, pass the correct configuration variables as command line options when invoking CMake.
For example:

```console
$ mkdir build && cmake -DKokkos_ARCH_CUDA=ON -DKokkos_ENABLE_CUDA=ON -B build/
```

Consult the [Kokkos configuration guide](https://kokkos.org/kokkos-core-wiki/get-started/configuration-guide.html) to see the appropriate configuration flags to use for your hardware.

## Building

Once CMake has been invoked to correctly set up the project, you may build the project via

```console
$ cmake --build build/
```

## Executing

Execute the demo by running

```console
$ ./build/GameOfLife_[CPU, Kokkos]
```

as desired.
You can add the flag `--kokkos-print-configuration` to get a summary of how Kokkos was built and verify that it is executing on the device.
Also, you will get a warning message that is conditionally compiled into the executable if the core function is complied for execution on the host instead of the device.
This warning message will be repeated on *each* inner loop execution, so I recommend starting with a small game board at first.
Follow the on-screen prompts to set up and execute a Game of Life simulation.

## Developer Notes

The source code has been commented with notes discussing the addition of Kokkos.
The goal of this demo was to show minimally disrupting the existing code so that GPU capabilities may be added incrementally.
